# Исследование видеохостинга: проверка статистических гипотез о популярности контента

Сбор данных о топ-2000 видео крупного видеохостинга, разведочный анализ и проверка гипотез о том, что влияет на просмотры и вовлечённость аудитории: длительность, тип контента и время публикации.

## Данные

- **2 147** видео, опубликованных в 2011–2025
- Поля: название, просмотры, длительность, лайки и дизлайки, комментарии, дата, категории, теги, хотспоты (на каких моментах видео зрители задерживаются дольше)

## Что сделал

- Собрал данные о видео через API
- Распарсил категории, теги и хотспоты из строк в списки, сделал one-hot encoding категорий, убрал дубли между категориями и тегами
- Сгруппировал годы в 4 эры, чтобы сгладить годы с малым числом видео
- Построил метрики вовлечённости: доля лайков, лайки, дизлайки и комментарии на 1 000 просмотров
- По хотспотам нашёл пиковый момент каждого видео
- Построил матрицу совместной встречаемости и условных вероятностей для топ-25 категорий
- Проверил 3 гипотезы с помощью z-теста, критериев Краскела — Уоллиса и Манна — Уитни

## Инсайты

- **Аудитория почти не ставит дизлайки:** нет ни одного видео, где дизлайков больше, чем лайков. Лайки и просмотры коррелируют на 0,95, поэтому лайки отдельно мало что добавляют к просмотрам
- **Комментарии распределены равномернее просмотров:** даже невирусные видео стабильно собирают 100–300 комментариев
- **Любительский контент нравится больше профессионального:** доля лайков у любительских видео выше
- **Длительность видео меняется со временем:** средняя длительность значимо различается между эрами
- **Видео на 40–60 минут набирают больше просмотров**, чем короче или длиннее
- **14 категорий растут в просмотрах в 2022–2024.** Часть из них пока не входит в топ-20 по просмотрам — это потенциальные точки роста контента

## Технологии

Python, pandas, NumPy, SciPy, matplotlib, seaborn, регулярные выражения
